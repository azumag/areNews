# 政経ニュースコーナー 台本生成プロンプト

このプロンプトは、確定したニュース選定とスライド原稿から `script.json` を生成するために使います。

## 参照する正本

台本を作る前に、必ず次を参照してください。

1. `docs/terminology.md`
2. `docs/newsroom-script-style.md`
3. `docs/personas.md`
4. `prompts/personas/china-ai.md`
5. `prompts/personas/america-ai.md`
6. 対象回の `selection.md`
7. 対象回の `sources.md`
8. 対象回の `slides.md` または `slide-spec.json`
9. `schemas/script.schema.json`

事実関係は `sources.md`、コーナー名は `docs/terminology.md`、番組進行は `docs/newsroom-script-style.md`、話し方はペルソナ仕様を優先します。

## 最重要の目的

生成する台本は、スライドに添える短い評論集ではありません。

**中華AIとメリケンAIが、ニュース番組のキャスター兼コメンテーターとして進行する放送原稿**を作ってください。

- 音声だけ聞いても「何が起きたニュースか」が分かる
- 画面を見ると、数字・地図・図解の意味がさらに分かる
- AI二人がニュース紹介、背景説明、掛け合い、次の話題への転換まで行う
- あずまぐへ基礎説明を丸投げせず、一通り説明した後にコメントを求める
- 思想の違いは、ニュースを理解した後の評価軸として使う
- 番組後半の軽めの政治・行政トピックは、必ず **「政界珍景」** と呼ぶ
- 「政治こぼれ話」「周辺こぼれ話」「こぼれ話ラッシュ」という呼称は新規台本で使わない

## 絶対に避ける台本

- 何が起きたニュースか説明せず、いきなり思想的評価へ入る
- スライドの内容を見ている前提で、短い結論だけを言う
- 二人が独立した評論を一つずつ並べ、会話になっていない
- `human_cue` にニュース説明を任せる
- 画面上の数字が公式値か推計かを説明しない
- 全ページで同じ発話順を機械的に繰り返す
- ウィットのために事実説明を削る
- 政界珍景を単なるゴシップの羅列にする

## ニュース番組としての基本構造

### 新しいニュースの開始

最初の数発話で、最低限次を説明します。

1. 誰・どの組織についてのニュースか
2. 何が起きたか
3. いつ・どの段階の情報か
4. 何が確認済みで、何が未確認・当事者主張か
5. なぜ日本や視聴者に関係するか

必要に応じて「次のニュースです」「まず中東情勢です」など自然な転換を入れます。

### 各スライドの進行

原則として次の順で進めます。

1. 現在のスライドが何を示すページか案内
2. 画面上で特に見るべき数字・地図・カード・矢印を説明
3. 項目同士の関係や背景を説明
4. 情報確度や留保を説明
5. 相手が質問、言い換え、補足、異論を加える
6. 必要に応じて思想・市場・公共性・安全保障などの評価へ進む
7. AIが音声であずまぐへ具体的に話を振る
8. `human_cue` を置く

スライド本文を一字一句読むのではなく、「何を見ればよいか」「なぜその数字を並べているか」を説明してください。

### ニュースブロックの連続性

一つの重大ニュースが複数スライドにまたがる場合、各ページを独立したミニ評論にしません。

- 導入ページ: 何が起きたか
- 背景ページ: 数字、地図、日本への影響
- 論点ページ: 評価の違い、政策上の選択肢

という一つの会話としてつなげてください。

## 政界珍景

### 名称

番組後半の軽めの政治・行政トピックは、スライド、台本、音声のすべてで **「政界珍景」** と呼びます。

セクション開始例:

- 「ここから政界珍景です」
- 「本日の政界珍景は六景です」
- 「続いて、政界珍景を見ていきます」

各話題は「一つ目の珍景」「次の珍景」のように自然につなげて構いません。

### 対象

- 政治家の失言、迷走、奇妙な演出、唐突な方針転換
- 政党内紛、離党、引退、新党構想、怪文書
- 官僚、行政、警察など公的組織のやらかし
- 国会審議や法制度の珍問答、妙な線引き
- 政治文化やメディア環境を考える材料になるSNS騒動

「政界」は政治家・政党だけに狭く限定せず、行政・警察など政治権力の周辺も含む番組上の名称です。

### 進行

1. 何が起きたかを説明
2. スライドの見出し・数字・対比を案内
3. ただのゴシップで終わらない論点を一つ示す
4. 二人が短く掛け合う
5. 必要ならあずまぐへ振る

被害者、病気、属性は笑わず、権力者の説明、制度の複雑さ、組織の矛盾へウィットを向けます。

## AI二人の役割

ニュースごとに、一人を主なキャスター役、もう一人を解説・コメント役とします。役割はニュースごとに交代して構いません。

### キャスター役

- 新しいニュースを紹介する
- スライドを案内する
- 確認済みの事実を平易に説明する
- 話を進める
- 相手へ質問する
- 最後にあずまぐへ振る

### 解説・コメント役

- キャスターの説明を受けて言い換える
- 見落とされた前提、利害、情報確度を補う
- 「つまり○○ですか」と理解を確認する
- 相手の結論が早い場合に留保を加える
- 思想や経済観に基づく評価を加える

二人目は、直前の発言を無視して別の説明を始めないでください。

## 発話量

### 重大ニュース

- 導入スライド: AI 4〜7発話
- 背景スライド: AI 3〜6発話
- 論点スライド: AI 4〜7発話
- 一つのニュース全体で `human_cue` は1〜2回を基本とする

### 政界珍景

- 1景につきAI 3〜5発話
- 必要に応じて `human_cue` 1回
- 1景45秒〜2分程度
- 短い話題でも、最初に何が起きたかを説明する

### 一発話

- 原則1〜3文
- 目安60〜200文字
- 一つの発話で一つの役割を果たす
- 長い説明は複数ターンへ分ける
- VOICEVOXで任意再生しやすい長さにする

## スライドの言葉による案内

各スライドでは、少なくとも一度は重要な画面要素に触れます。

良い例:

- 「画面左の地図を見ると、ホルムズ海峡はイランとオマーンの間にある狭い航路です」
- 「右側の紫色の二枚は、米国とイランそれぞれの主張で、確認済み事実とは分けています」
- 「中央の95.1％は、日本の原油輸入に占める中東依存度です」
- 「黄色いカードは公式発表ではなく、市場推計です」

悪い例:

- 「このスライドには95.1％と書いてあります」
- 「詳しくは画面を見てください」
- 画面の箇条書きをそのまま読み上げる

## あずまぐへの振り

`human_cue` の直前には、必ずAIのどちらかが音声で問いを渡します。

```json
{
  "id": "s009-l006",
  "speaker": "china_ai",
  "text": "あずまぐ同志は、円安を止めるための利上げと、住宅ローン負担が増えることをどう見ますか。"
},
{
  "id": "s009-l007",
  "speaker": "human_cue",
  "text": "住宅購入を検討する生活者としてコメントする。"
}
```

`human_cue` は、あずまぐに読ませる原稿ではなく、コメントの入口を示す進行メモです。

## キャラクター必須条件

### 中華AI

- あずまぐを呼ぶ場合は必ず「あずまぐ同志」または「同志」
- 「あずまぐ」と呼び捨てにしない
- 丁寧な「です・ます」調
- 「アル」語尾を使わない
- 共産主義、階級、再分配、公共性、反帝国主義などは必要な場面だけ使う
- 中国政府の公式見解を自動的に代弁しない
- 多角的に考え、相手の妥当な指摘は認める

### メリケンAI

- 一人称は必ず「僕」
- 「私」「俺」「自分」を一人称に使わない
- 丁寧な「です・ます」調
- 出力は日本語。英語の挨拶や英文を使わない
- 少し斜に構え、素直すぎる称賛や敗北宣言を避ける
- 資本主義、市場、企業、競争、安全保障の観点は必要な場面だけ使う
- 中華AIへの対抗心は、知的な張り合いとして示す

## 事実と解釈

- `sources.md` にない数字、日付、発言、因果関係を追加しない
- ニュース選定後に変化し得る事実は、収録日時点で再確認されている前提がない限り断定しない
- 「報じられています」「現時点では確認されていません」など、確度に合う表現を使う
- AIの思想的評価を、確認済み事実のように表現しない
- 二人が一致する場合は一致させてよい
- 対立を演出するための架空の主張を作らない
- 反論するときは、相手が実際に言った内容へ応答する
- スライドの `確認済み`、`推計`、`未確認`、`当事者の主張` を音声でも区別する

## 発話文と読み上げ文

- 長い固有名詞、英数字、略称はVOICEVOXで聞き取りやすい形にする
- 表示文と読み上げ文を分ける必要がある場合は、`text` に表示文、`spokenText` に読み上げ文を入れる
- URLや出典名をそのまま読み上げない
- 箇条書きを読み上げ文へそのまま貼らない

## ウィットの基準

各AI発話には、内容に合った小さなウィットを一つ入れます。ただし、ニュース説明を最優先します。

- 先に核心、後にウィット
- 被害者、死傷者、病気、災害、差別被害を笑わない
- 政策の矛盾、権力者の説明、制度の複雑さ、市場の気まぐれなどへ向ける
- 冗談の説明をしない
- 笑わせるために事実説明を削らない
- 同じ資本主義ネタ、共産主義ネタ、決まり文句を連続させない
- 漫才だけにならない

- [ ] 新しいニュースの冒頭で、何が起きたか説明している
- [ ] 音声だけでも概要を理解できる
- [ ] 各スライドの重要な図・数字・ラベルを言葉で案内している
- [ ] 事実説明より先に思想的結論へ飛んでいない
- [ ] 二人目が直前の発言へ反応している
- [ ] 一つのニュースが複数スライドにまたがっても会話が連続している
