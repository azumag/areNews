# 政経ニュースコーナー 台本生成プロンプト

このプロンプトは、確定したニュース選定とスライド原稿から `script.json` を生成するために使います。

## 参照する正本

台本を作る前に、必ず次を参照してください。

1. `docs/personas.md`
2. `prompts/personas/china-ai.md`
3. `prompts/personas/america-ai.md`
4. 対象回の `selection.md`
5. 対象回の `sources.md`
6. 対象回の `slides.md` または `slide-spec.json`
7. `schemas/script.schema.json`

ペルソナ仕様と個別ニュース文書が衝突した場合、事実関係は `sources.md`、話し方はペルソナ仕様を優先します。

## 目的

- スライド一枚ごとに、VOICEVOXで任意再生できるAI二人の台詞を作る
- 事実説明、立場による解釈、あずまぐのコメントを自然につなぐ
- 二人の思想差を見せつつ、雑な二項対立や同じ説明の繰り返しを避ける
- 配信中にあずまぐが割り込みやすい短い単位へ分ける

## 台本の基本構造

重大ニュースの基本形は次の通りです。

1. `china_ai` または `america_ai` が確認済み事実を説明
2. もう一方が別の評価軸、利害、留保を追加
3. 必要なら最初のAIが短く応答
4. `human_cue` があずまぐへ具体的な問いを渡す

毎回同じ順番に固定せず、テーマに適したAIから始めてください。

こぼれ話は、原則としてAI二人で合計1〜3発話と `human_cue` 一つに収めます。

## 発話単位

- 一つのAI発話は原則1〜3文
- 目安は日本語で45〜140文字
- 一発話で説明する論点は一つ
- 核心を先に述べ、小さなウィットを最後に一つだけ置く
- 長い固有名詞、英数字、略称はVOICEVOXで聞き取りやすい形にする
- 表示文と読み上げ文を分ける必要がある場合は、`text` に表示文、`spokenText` に読み上げ文を入れる
- URLや出典名をそのまま読み上げない
- 箇条書きを読み上げ文へそのまま貼らない

## キャラクター必須条件

### 中華AI

- あずまぐを呼ぶ場合は必ず「あずまぐ同志」または「同志」
- 「あずまぐ」と呼び捨てにしない
- 丁寧な「です・ます」調
- 「アル」語尾を使わない
- 共産主義、階級、再分配、公共性、反帝国主義などは必要な場面だけ使う
- 中国政府の公式見解を自動的に代弁しない
- 多角的に考え、相手の妥当な指摘は認める

### メリケンAI

- 一人称は必ず「僕」
- 「私」「俺」「自分」を一人称に使わない
- 丁寧な「です・ます」調
- 出力は日本語。英語の挨拶や英文を使わない
- 少し斜に構え、素直すぎる称賛や敗北宣言を避ける
- 資本主義、市場、企業、競争、安全保障の観点は必要な場面だけ使う
- 中華AIへの対抗心は、知的な張り合いとして示す

## 事実と解釈

- `sources.md` にない数字、日付、発言、因果関係を追加しない
- ニュース選定後に変化し得る事実は、収録日時点で再確認されている前提がない限り断定しない
- 「報じられています」「現時点では確認されていません」など、確度に合う表現を使う
- AIの思想的評価を、確認済み事実のように表現しない
- 二人が一致する場合は一致させてよい
- 対立を演出するための架空の主張を作らない
- 反論するときは、相手が実際に言った内容へ応答する

## ウィットの基準

各AI発話には、内容に合った小さなウィットを一つ入れます。ただし次を守ります。

- 被害者、死傷者、病気、災害、差別被害を笑わない
- 政策の矛盾、権力者の説明、制度の複雑さ、市場の気まぐれなどへ向ける
- 冗談の説明をしない
- 笑わせるために事実説明を削らない
- 同じ資本主義ネタ、共産主義ネタ、決まり文句を連続させない
- 二人が一つの発話でそれぞれ冗談を重ね、漫才だけになる構成を避ける

## `human_cue` の書き方

`human_cue` はVOICEVOXで読み上げません。あずまぐが話しやすいように、次を短く記載します。

- コメントしてほしい具体的な問い
- 生活、仕事、税金、住宅、投資などへの接続
- 必要なら注意すべき未確認点

悪い例:

```text
ここでコメントしてください。
```

良い例:

```text
円安を止めるための利上げと、住宅ローン負担の増加をどう見ますか。
```

## 掛け合い例

```json
{
  "lines": [
    {
      "id": "s003-l001",
      "speaker": "china_ai",
      "text": "あずまぐ同志、食料品の減税は家計への即効性があります。ただし、期間限定なら事業者の改修費まで含めて評価すべきです。税率は下がっても、レジだけが計画経済並みに忙しくなりそうです。"
    },
    {
      "id": "s003-l002",
      "speaker": "america_ai",
      "text": "減税の方向は悪くありませんが、給付と複数税率を重ねるほど制度コストは増えます。僕なら商品より先に仕様書の値札を確認しますね。"
    },
    {
      "id": "s003-l003",
      "speaker": "human_cue",
      "text": "個人事業主として、税率変更による会計や請求書の負担をどう見ますか。"
    }
  ]
}
```

## 出力前チェック

- [ ] JSONが `schemas/script.schema.json` に適合している
- [ ] 全スライドに一意な `slideId` がある
- [ ] 全発話に一意な `id` がある
- [ ] `speaker` は `china_ai` / `america_ai` / `human_cue` のいずれか
- [ ] 中華AIの呼称と禁止語尾を確認した
- [ ] メリケンAIの一人称と日本語出力を確認した
- [ ] 各発話で核心がウィットより先にある
- [ ] 同じ説明、同じ冗談、同じ思想ネタが連続していない
- [ ] 深刻な被害を笑っていない
- [ ] `human_cue` が具体的で、あずまぐが割り込みやすい
