# 政経ニュースコーナー設計

## コンセプト

硬いニュースを、思想の違うAI二人の掛け合いと、人間コメンテーターの生活者視点で見せる。

ポイントは、単なるニュース読み上げではなく、次の三層に分けること。

1. 事実確認: 何が起きたか
2. 解釈の分岐: 立場によってどう見えるか
3. 生活への接続: 視聴者に何が関係するか

## 1回の構成

```text
00:00  オープニング
01:00  今日の重大ニュース一覧
02:00  重大ニュース1
08:00  重大ニュース2
14:00  重大ニュース3 任意
20:00  周辺こぼれ話ラッシュ
27:00  今日のまとめ・人間コメント
```

## ニュース分類

### 重大ニュース

国際情勢・国内政治・経済のうち、生活・市場・制度・安全保障への影響が大きいもの。

例:

- 中東情勢、戦争、停戦交渉、資源価格
- 米国政治・金融政策・日本経済への波及
- 消費税、社会保障、物価対策、選挙制度

### 周辺こぼれ話

重大ニュースほどではないが、政治文化や統治の雑さが見えるもの。

例:

- 政治家の失言・迷走・唐突な方針転換
- 警察・行政・官僚組織のやらかし
- 政党内の内紛、離党、引退、怪文書
- SNSで燃えたが、背景を読むと意外に重要な話

## キャラクター設計

### 中華AI

- 観点: 国家、階級、公共投資、再分配、反帝国主義、資源安全保障
- 口調: やや断定的。語尾に少しだけ「アル」を混ぜてもよいが、使いすぎない
- 禁止: 実在国民・民族への嘲笑、差別、陰謀論の断定

### メリケンAI

- 観点: 市場、企業利益、投資家心理、自由競争、安全保障同盟
- 口調: 陽気で強気。過度に広告っぽくしない
- 禁止: 弱者切り捨てを肯定しすぎない、事実不明な市場予測を断定しない

### 人間コメンテーター

- 観点: 生活費、税金、仕事、住宅、投資、子育て、地域生活
- 役割: AI二人の極端な意見を受けて、現実的な落としどころや違和感を話す

## 保存単位

1回分を `episodes/YYYY-MM-DD-slug/` に保存する。

```text
episodes/2026-08-04-first-test/
  selection.md      採用ニュースと候補落ちニュース
  sources.md        参照元URL・一次情報・未確認点
  slides.md         スライド原稿
  slide-spec.json   スライド生成用の構造データ
  script.json       読み上げ用台本
  notes.md          収録後メモ
```

## Google Slides 連携方針

リポジトリには、Google Slidesそのものではなく、再生成可能な `slide-spec.json` と `slides.md` を保存する。

次段階で、Google Slides API に `slide-spec.json` を渡してプレゼンを作成・更新する。

## VOICEVOX連携方針

Tauri アプリは `script.json` を読み込み、スライド単位で以下を手動再生できるようにする。

- 中華AIのセリフ
- メリケンAIのセリフ
- 次のセリフ
- 停止

最初は完全自動進行にしない。人間が話し始めたら止められることを優先する。
