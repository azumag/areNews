# 番組内の用語

## 政界珍景

次回以降、これまで「政治こぼれ話」「周辺こぼれ話」「こぼれ話ラッシュ」と呼んでいた番組後半のコーナーは、正式名称を **「政界珍景」** とする。

### 対象

重大ニュースとして長く扱うほどではないが、政治文化、権力関係、組織統治、制度の妙な境界が見える話題を扱う。

- 政治家の失言、迷走、奇妙な演出、唐突な方針転換
- 政党内紛、離党、引退、新党構想、怪文書
- 官僚、行政、警察など公的組織のやらかし
- 国会審議や法制度で生じた珍問答、妙な線引き
- SNS上の政治的騒動のうち、政治文化やメディア環境を考える材料になるもの

「政界」という語は政党・政治家だけに狭く限定せず、行政・警察など政治権力の周辺も含む番組上の名称として使う。

### 扱い方

- 単なるゴシップの羅列にしない
- 最初に何が起きたかを説明する
- その出来事から見える制度、組織文化、責任の所在を一つ示す
- 被害者、病気、属性を笑いの対象にしない
- 笑いは権力者の説明、制度の複雑さ、組織の矛盾へ向ける
- 原則として1件45秒〜2分程度で、重大ニュースよりテンポよく進める

### 表示ルール

- スライドのセクション名: `政界珍景`
- 見出し例: `ここから政界珍景`、`本日の政界珍景 6景`
- 台本上も「こぼれ話」という呼称は使わず、「政界珍景」または「珍景」と呼ぶ
