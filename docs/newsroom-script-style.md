# ニュース番組型 台本スタイル

## 目的

政経ニュースコーナーの台本は、スライドに添える短い論評集ではなく、**中華AIとメリケンAIが番組を進行するニュース原稿**とする。

視聴者が画面を見ていなくても「何が起きたニュースなのか」を理解でき、画面を見れば数字・地図・図解の意味がさらに分かる状態を目指す。

あずまぐはニュースの読み手ではなく、AI二人から話を振られて参加する人間コメンテーターである。

番組後半の軽めの政治・行政トピックは、正式名称を **「政界珍景」** とする。対象範囲と表示ルールは `docs/terminology.md` に従う。

## 出演者の役割

### 中華AI・メリケンAI

二人とも次の役割を担う。

- 番組の進行
- ニュースの紹介
- 事実関係と背景の説明
- スライド上の数字・図・ラベルの案内
- 相手の説明への質問、補足、異論
- 思想や利害の違いに基づくコメント
- あずまぐへの話題の受け渡し
- 次のスライド・次のニュースへの転換

テーマごとに一人を主なキャスター役、もう一人を解説・コメント役にする。役割はニュースごとに交代してよい。

### あずまぐ

- AI二人がニュースを一通り説明した後にコメントする
- 生活、仕事、住宅、投資、税金、地域社会などへ引き寄せる
- AI二人の解釈に同意、反論、留保を加える
- 必要に応じて途中で割り込む

## 最重要ルール

### 1. 音声だけでもニュースが分かる

新しいニュースを始めるときは、最初の数発話で最低限、次を説明する。

- 誰・どの組織に関する話か
- 何が起きたか
- いつ・どの段階の情報か
- 何が確認済みで、何が未確認か
- なぜ今取り上げるのか

背景を知っている視聴者だけを前提にしない。

### 2. スライドを言葉で案内する

各スライドでは、少なくとも一度は画面上の重要な要素へ自然に触れる。

例:

- 「画面左の地図を見ると、ホルムズ海峡はイランとオマーンの間の狭い航路です」
- 「右側には、米国とイランの相反する説明を分けて表示しています」
- 「大きく出ている95.1％は、日本の原油輸入に占める中東依存度です」
- 「黄色のカードは公式値ではなく市場推計です」

単に「このスライドには○○と書いてあります」と読み上げるのではなく、**何を見ればよいか、項目同士がどうつながるか**を説明する。

### 3. 事実説明より先に思想コメントへ飛ばない

ニュース導入直後から、共産主義・資本主義・帝国主義・自由市場の話だけを始めない。

順序は原則として次の通り。

1. ニュースの概要
2. スライドの案内
3. 背景と重要性
4. 確認済み事実と留保
5. 二人の解釈・掛け合い
6. あずまぐへの振り

### 4. 二つの独立解説ではなく会話にする

二人目は、最初の発言を無視して別のミニ解説を始めない。

次のいずれかを行う。

- 内容を言い換えて視聴者の理解を確認する
- 「つまり○○ということですか」と質問する
- 見落とされた利害や前提を補う
- 数字の読み方や情報確度を訂正する
- 一部へ同意してから異なる評価を加える
- 相手の結論が早すぎると指摘する

### 5. あずまぐへは、AIの音声で話を渡す

`human_cue` の直前には、AIのどちらかが実際に読み上げる形で問いを投げる。

例:

```text
中華AI: あずまぐ同志は、円安を止めるための利上げと、住宅ローン負担の増加をどう見ますか。
human_cue: 住宅購入を検討する生活者としてコメントする。
```

`human_cue` だけを突然置かない。

## ニュースブロックの標準構造

重大ニュースは、複数スライドを一つのニュース番組ブロックとして構成する。

### A. 導入スライド

- 「次のニュースです」などの自然な転換
- 何が起きたかを平易に説明
- 地図・当事者・数字の見方を案内
- 確認済み事実と当事者主張を分ける

### B. 背景・生活への影響

- 大きな数字や因果関係を説明
- なぜ日本や視聴者に関係するかを示す
- 相手が疑問や補足を入れる

### C. 論点・見方の違い

- 二人の評価軸を出す
- 相手の妥当な点には同意してよい
- 架空の対立を作らない
- 最後にあずまぐへ具体的な問いを渡す

政界珍景でも、最初に「何が起きたか」を説明し、その後に制度・組織文化・責任の所在を一つ示す。

## 発話量の目安

### 重大ニュース

- 導入スライド: AI 4〜7発話
- 背景スライド: AI 3〜6発話
- 論点スライド: AI 4〜7発話
- 一つのニュース全体で `human_cue` は1〜2回を基本とする

### 政界珍景

- AI 3〜5発話
- `human_cue` 1回
- 1景あたり45秒〜2分程度
- セクション開始時は「ここから政界珍景です」など、正式名称を音声でも告げる

### 一発話

- 原則1〜3文
- 目安60〜200文字
- 一つの発話で一つの役割を果たす
- 長い説明は複数の会話ターンへ分ける

## ウィットの位置

- 先に説明、後に小さなウィット
- 事実説明を冗談で置き換えない
- 被害者・病気・死傷者を笑わない
- 深刻なニュースでは、政策の矛盾、権力者の説明、市場や制度の不合理へ向ける
- 一つの発話に複数の冗談を詰め込まない

## 悪い例

```text
中華AI: 円安の痛みは労働者へ押し付けられています。市場の椅子取りゲームですね。
メリケンAI: 介入は合理的ですが長続きしません。全員が勝つ為替水準は上場されていません。
```

問題点:

- 何が起きたニュースか説明していない
- スライド上の数字を説明していない
- 二人が互いに反応していない
- 視聴者が前提知識を持つことを要求している

## 良い例

```text
メリケンAI: 次は円相場です。画面上の折れ線は、円が一ドル164円付近まで下落した後、日米の円買い介入で急反発した流れを示しています。為替はニュース速報より先に走ります。

中華AI: 右下に二つの金額がありますが、同じ数字ではありませんね。11兆7,349億円は前回期間について財務省が公表した公式額、365.8億ドルは今回分についての市場推計です。

メリケンAI: その通りです。推計を公式発表のように扱うと、ニュースではなく数字のコスプレになります。今回珍しいのは、日本だけでなく米国も円買いに参加した点です。

中華AI: では、介入で円安問題は解決したのでしょうか。

メリケンAI: 短期的には投機の勢いを止められます。ただ、日米の金利差や日本の財政への見方が変わらなければ、介入は時間を買う措置です。

中華AI: あずまぐ同志は、円安を止める利上げと、住宅ローン負担が増えることをどう見ますか。

human_cue: 住宅購入を検討する生活者としてコメントする。
```

## 台本レビューのチェック項目

- [ ] 新しいニュースの冒頭で、何が起きたか説明している
- [ ] 音声だけでも概要を理解できる
- [ ] 各スライドの重要な図・数字・ラベルを言葉で案内している
- [ ] スライド本文を機械的に読み上げるだけになっていない
- [ ] 事実説明より先に思想的結論へ飛んでいない
- [ ] 二人目が直前の発言へ反応している
- [ ] 一つのニュースが複数スライドにまたがっても会話が連続している
- [ ] AIの音声による問いの後に `human_cue` がある
- [ ] あずまぐにニュースの基礎説明を丸投げしていない
- [ ] 政界珍景の名称を「こぼれ話」に戻していない
- [ ] ウィットが説明を邪魔していない
