# 運用手順

## 1. ニュース候補を出す

まず、配信日の直近ニュースから以下を作る。

- 重大ニュース候補: 8〜12件
- 政界珍景候補: 15〜25件

政界珍景には、政治家・政党だけでなく、官僚、行政、警察など政治権力の周辺で起きた珍事ややらかしも含める。詳しい定義は `docs/terminology.md` を参照する。

各候補には、必ず以下を書く。

- 何が起きたか
- なぜ重要か
- 配信で話す価値
- 事実確認の強さ
- 反対解釈・留保
- 使えるキャラ掛け合い

## 2. 人間と壁打ちして採用する

採用基準は以下。

- 生活・税金・仕事・市場・安全保障に接続できる
- 中華AIとメリケンAIの対立軸が作れる
- 人間コメントで「で、結局どう見る？」に落とせる
- 情報源が弱すぎない
- 重大ニュースと政界珍景の温度差がある

## 3. episodeディレクトリを作る

例:

```text
episodes/2026-08-04-middle-east-tax-yen/
```

最低限、以下を保存する。

```text
selection.md
sources.md
slides.md
script.json
```

## 4. スライドを作る

1スライド1論点。

おすすめ構成:

1. タイトル
2. 今日の見出し
3. 重大ニュース1: 事実
4. 重大ニュース1: 見方の対立
5. 重大ニュース2: 事実
6. 重大ニュース2: 見方の対立
7. 重大ニュース3: 事実 任意
8. 政界珍景
9. 今日のまとめ

政界珍景のセクションスライドでは「ここから政界珍景」「本日の政界珍景 6景」などの名称を使い、「こぼれ話」という表示は使わない。

## 5. 台本を作る

`script.json` は、スライドごとにセリフを並べる。

- `speaker`: `china_ai` / `america_ai` / `human_cue`
- `text`: 読み上げ本文
- `voicevoxSpeakerId`: VOICEVOX話者ID
- `note`: 人間向けメモ

## 6. 読み上げ

1. VOICEVOX Engine を起動する
2. `apps/controller` を起動する
3. `script.json` を読み込む
4. スライドを進めながら、AIごとのボタンで手動再生する

## 7. 収録後

`notes.md` に残す。

- ウケた話題
- 長すぎた話題
- 次回も追うべきニュース
- 台本で読みづらかった箇所
- スライドで情報過多だった箇所
