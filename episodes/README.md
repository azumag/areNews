# episodes

各回の素材を保存します。

## 命名

```text
YYYY-MM-DD-short-slug
```

例:

```text
2026-08-04-middle-east-yen-tax
```

## 1回分の基本ファイル

```text
selection.md      ニュース選定と採用判断
sources.md        情報源、一次情報、未確認点
slides.md         スライド原稿
slide-spec.json   スライド生成用データ
script.json       VOICEVOX読み上げ用台本
notes.md          収録後メモ
```

ニュース候補だけ先に保存し、採用後に `slides.md` と `script.json` を追加していく運用でよいです。
